# Kart-Food

A modern, responsive dessert ordering app built with React, Vite, TypeScript, MUI and styled-components.

## 📱 Responsive Design

- **Mobile & Tablet:**  
  - The cart/order summary appears at the top.
  - Product cards are stacked vertically, one per row.
- **Desktop:**  
  - Product cards are displayed in a grid on the left.
  - The cart/order summary is displayed on the right.

> 💡 The layout automatically adapts to all screen sizes for a seamless user experience.

---

## 🚀 Tech Stack

- **React** (with hooks)
- **TypeScript**
- **styled-components** for styling and responsive layouts
- **Material-UI** for UI components (e.g., loading spinner)
- **Custom theme** for consistent colors and spacing
